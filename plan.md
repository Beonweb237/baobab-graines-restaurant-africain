# Plan : Site Web Restaurant Africain

## Objectif
Créer un site web professionnel, chaleureux et authentique pour un restaurant africain avec une ambiance immersive et des couleurs terreuses/vibrantes.

## Étapes

### Étape 1 — Design & Assets
- Créer un design Guide (design.md) avec palette de couleurs chaudes et terreuses
- Générer les assets visuels nécessaires (hero image, photos de plats, etc.)
- Préparer le Technical Specification

### Étape 2 — Développement Web
- Charger le skill `vibecoding-webapp-swarm`
- Construire le site React avec toutes les sections
- Intégrer les animations et effets visuels

### Étape 3 — Déploiement
- Compiler et déployer le site

## Sections du site
1. **Hero** — Image immersive, nom du restaurant, tagline, CTA
2. **À propos** — Histoire du restaurant, chef, authenticité
3. **Menu** — Carte des plats africains avec photos et prix
4. **Galerie** — Photos du restaurant et des plats
5. **Témoignages** — Avis clients
6. **Réservation** — Formulaire de réservation
7. **Contact** — Adresse, horaires, téléphone, map
8. **Footer** — Liens, réseaux sociaux

## Design Direction
- Palette : tons terreux (ocre, terracotta, sable), accents verts (sauge), or chaleureux
- Typographie : élégante avec une touche ethnique
- Ambiance : chaleureuse, accueillante, authentique
